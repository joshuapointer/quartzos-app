Quick Reference
Test a feature branch on your dev build
eas channel:edit development --branch your-branch-name
Reopen the app — it will fetch the latest update from that branch.
Test a feature branch on your preview build
eas channel:edit preview --branch your-branch-name
Inspect state
eas channel:list
See what EAS branch each channel is currently pointing at.
eas branch:list
See all published EAS branches and their update counts.
Publish a manual update (skip CI)
eas update --branch your-branch-name --message "quick fix"
💡
No build credits consumed. EAS Update only pushes JS + assets over-the-air to already-installed builds. Native code changes (new packages, config changes) still require a full eas build. The existing eas-build.yml workflow is untouched.
